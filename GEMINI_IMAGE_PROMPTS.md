# Gemini Image Generation Prompts (Midnight Documentary)

This file contains standalone, ready-to-copy prompts for every image required by the Great America's Sleep Contest website. Every prompt combines the **Style Lock v2** documentary rules with the specific subject details.

---

## Instructions for Generating & Dropping In Images

1. **Copy the prompt** for each image into Gemini / Imagen.
2. **Download the generated image** and save it to the specified file path below.
   - Images can be saved as `.webp`, `.png`, or `.jpg`.
   - WebP is preferred for smallest file size.
3. **Run the scan command**:
   ```bash
   npm run assets:scan
   ```
   The site will immediately detect the new images and upgrade from the cinematic dark gradient fallbacks to the real photographs!
